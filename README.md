# 💻 Code Philosophy

```python
while True:

    idea = get_idea()

    if idea:
        prototype(idea)

    if prototype_works():
        improve(idea)

    if it_solves_a_real_problem():
        ship()

    learn()
```

### My rule:

**Build → Break → Debug → Learn → Rebuild → Ship.**
